# 全局认知与高效学习助手

一个以目标为中心的学习与工作辅助插件：先建立领域地图，再筛选当前重点，并用真实任务或可检查的交付物验证理解与完成情况。

## 能做什么

- 为陌生领域建立知识结构和学习顺序。
- 标注「先学」「按需查」「暂缓」的内容。
- 用贴近目标的案例解释关键原理。
- 通过练习、作品或工作交付检查掌握情况。
- 按实际证据补充卡点，并把学习方法迁移到真实工作。

## 安装与使用

本仓库用于公开插件源文件，方便查看、下载和后续分发。GitHub 仓库公开后，不会自动将插件加入 ChatGPT 插件目录或任何插件市场。

核心 Skill 位于 `skills/global-learning/SKILL.md`。在支持 Agent Skills 的环境中，可以将该文件作为 Skill 导入或纳入自己的插件项目。具体安装入口和打包方式取决于所用宿主的插件格式与版本；请按对应宿主的当前说明操作。

仓库中的 `plugin.json` 与 `.codex-plugin/plugin.json` 保留原项目的插件配置。若要提交到其他插件市场或分发平台，请先对照该平台当前的 manifest 规范，检查配置兼容性并完成其要求的验证。

## 示例请求

- 「我想系统学习 Excel 订单汇总，请先给我知识地图，再安排一个实操任务。」
- 「帮我快速理解这个领域，区分必须先学、遇到时再查和暂缓学习的内容。」
- 「这是我的实操结果，请按证据指出已掌握部分和具体卡点。」
